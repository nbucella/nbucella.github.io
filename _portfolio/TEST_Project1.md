**The Problem** The marketing team needed to understand why users were leaving after the trial period.

**The Solution** I analyzed 50k+ user logs using Python and SQL to track user journey drop-off points. I visualized the results in Tableau to highlight the friction points during onboarding.

**Key Insight** Users who didn't engage with feature X within the first 3 days were 80% more likely to churn.

**Tools Used** * Python (Pandas, Scikit-learn)
* SQL
* Tableau
